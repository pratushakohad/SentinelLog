
# SentinelLog

SentinelLog is a beginner-friendly C++ cybersecurity project
that reads log files and displays their contents.

## Current Features
- Reads a log file line by line.
- Displays log entries in the terminal.
- Handles cases where the log file cannot be opened.

## Technologies Used
- C++
- File handling (`ifstream` and `getline`)
- Visual Studio Code
- GCC (g++)

## How to Run

1. Install a C++ compiler such as GCC.
2. Open the project folder in your terminal.
3. Compile the program:

   g++ main.cpp -o SentinelLog

4. Run the program on Windows:

   .\SentinelLog.exe

Make sure `sample.log` is in the same folder as the executable.

## Project Status
Early development. More log-analysis features will be added.

## Learning Goals
- Understand log-file processing.
- Practise C++ file handling.
- Build a foundation for basic security-log analysis.
